Output a scalar
## Example： Estimating the Combat Power（CP） of a Pokemon after evolution 预测神奇宝贝的战斗力

## Step1: Model
先尝试线性模型
$y = b + wx_{cp}$
对于不同的b和w，我们可以得到$f_1,f_2,...$
## Step2: Goodness of Function
我们如何评判这些f的好坏呢
损失函数
$$L(f) = \sum_{n=1}^{10}{(\hat{y}^n - (b+wx_{cp}^n))^2}$$
由于f的参数就是b和w，所以也就是
$$L(W,b) = \sum_{n=1}^{10}{(\hat{y}^n - (b+wx_{cp}^n))^2}$$
Pick the Best function 
$$
f^* = arg\min_{f}L(f)
$$也就是
$$
w^*,b^* = arg\min_{f}L(w,b)
$$
如何求解？Gradient Descent
## Step3: Gradient Descent
### Consider L(w) with one parameter w:
Randomly pick an initial value $w^0$
Compute $\frac{dL}{dw}|_{w=w^0}$
if Negative,Increase w
if Positive,Decrease w
$$
w^1 \leftarrow w^0 -\eta\frac{dL}{dw}|_{w=w^0}
$$
$\eta$ is called learning rate
因为上面正负和w的变化相反，所以这里$\eta$前面有个负号
但是当遇到极值点的时候，将会停止
How to avoid local minmal value？

### How about two parameters?
Randomly pick an initial value $w^0,b^0$
Compute $$\frac{\partial L}{\partial w}|_{w=w^0,b=b^0},\frac{\partial L}{\partial b}|_{w=w^0,b=b^0}$$
if Negative,Increase w,b
if Positive,Decrease w,b
Define gradient

$$\triangledown L =\pmatrix{\frac{\partial L}{\partial w}\\ \frac{\partial L}{\partial b}}$$
$$
w^1 \leftarrow w^0 -\eta\frac{\partial L}{\partial w}|_{w=w^0,b=b^0}
$$
$$
b^1 \leftarrow b^0 -\eta\frac{\partial L}{\partial b}|_{w=w^0,b=b^0}
$$
### How is the results?-Generalization
Average Error $\frac{1}{10} \sum_{n=1}^{10}{e^n}$
结果可能是不理想的，那如何让误差更小？
可以选择换一个更好的模型
## Selecting another Model
$$
y = b + w_1 x_{cp}+w_2(x_{cp})^2
$$
注意这仍然是一个线性模型，只看参数！
随着次数的升高，训练集的误差会越来越小
因为高次的模型本身就包含了低次的模型（高次系数为0）
因此误差显然会更小

但是测试集的误差却并不如此，更复杂的模型并不总是会引向更好的结果，这种现象称为Overfitting 过拟合

太过复杂的模型总是会导致过拟合，从图像上来看，就是图像过于扭曲，不够平滑(为了贴合数据，可能就会出现飞跃，陡增陡降的情况)，会让图像变的比较尖锐

为了避免出现这种情况，我们就需要正则化
## Regularization
机器学习里的**正则化（Regularization）**，可以先把它理解成一句话：

> **在训练模型时，不光要求模型把训练数据拟合好，还要限制模型“别太复杂、别太极端”。**

它主要是为了防止**过拟合**。

假设我们本来做线性回归，损失函数是：

$$L(w,b)=\sum_{i=1}^n(y_i−(wx_i+b)^2)$$

训练的目标就是找到 w,b让误差尽可能小。

但如果模型比较复杂，它可能为了把训练集拟合得特别好，把参数搞得非常大。例如：
$$y=1000x_1-999x_2+0.001x_3+\cdots$$

这种模型可能在训练集上效果很好，但对新数据很敏感，泛化能力差。

于是我们在原来的损失函数后面加一个**惩罚项**：

$$\boxed{ L_{\text{new}} = L_{\text{original}} + \lambda R(w) }$$
这里：
- $\text{original}$：原来的预测误差
- R(w)：对模型复杂程度的惩罚
- λ：惩罚强度，也就是**正则化系数**

比如最经典的 **L2 正则化**：

$R(w)=\sum_j w_j^2$

所以：
$$\boxed{ L = \sum_i(y_i-\hat y_i)^2 + \lambda\sum_j w_j^2 }$$

这意味着模型现在面对两个目标：

预测误差要小预测误差要小

同时：参数不能太大

比如模型有两种选择：

模型A：误差=1,w=100
模型B：误差=1.2,w=2

如果没有正则化，肯定选模型 A，因为 1<1.21<1.2。

但加入正则化：
$$L=\text{误差}+\lambda w^2$$

假设：$\lambda=0.01$

那么 A：$L_A=1+0.01(100)^2=101$

B：$L_B=1.2+0.01(2)^2=1.24$

模型就会选 B。

虽然 B 在训练集上稍微差了一点，但通常在**没见过的数据上反而表现更好**。

你可以把它想象成学生做题：

**没有正则化：**  
“把这100道训练题答案全部背下来。”

**有正则化：**  
“尽量学规律，不允许靠特别复杂的死记硬背方式。”

所以正则化的本质就是：

用一点训练集性能，换取更好的泛化能力

顺便提一句，机器学习里不只有 L1/L2 算“正则化”。像神经网络里的 **Dropout、Early Stopping、数据增强（Data Augmentation）**，本质上也都具有正则化作用——都在想办法阻止模型把训练集“背下来”。

但是正则化系数也不能太大,不然就会导致欠拟合现象
