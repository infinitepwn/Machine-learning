# Where does the error come from?
error有两个来源，bias和variance
设$E(f^*) = \overline{f}$，variance自然就是$Var(f^*)$
那么$\overline{f}$和$\hat{f}$之间的差距叫做bias
欠拟合的时候，会导致大的bias
过拟合的时候，会导致大的variance
